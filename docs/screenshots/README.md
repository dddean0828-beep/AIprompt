# 功能界面截图目录

将各页面的功能展示图放在本目录下，文件名建议与主文档 `SYSTEM_IMPLEMENTATION.md` 中的引用一致。

## 推荐命名（与文档占位一一对应）

| 文件名 | 对应页面 |
|--------|----------|
| `01-login.png` | 登录页 |
| `02-register.png` | 注册页 |
| `03-home.png` | 首页（搜索 + 分类 + 卡片列表） |
| `04-prompt-detail.png` | 提示词详情 |
| `05-prompt-form.png` | 新增/编辑提示词 |
| `06-my-prompts.png` | 我的提示词管理 |
| `07-favorites.png` | 我的收藏 |
| `08-rank.png` | 排行榜 |

支持 `png`、`jpg`、`webp`。若使用其它文件名，请同步修改根目录 `SYSTEM_IMPLEMENTATION.md` 中的 Markdown 图片路径。
